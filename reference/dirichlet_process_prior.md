# Dirichlet-process prior for a latent partition

Dirichlet-process prior for a latent partition

## Usage

``` r
dirichlet_process_prior(concentration = 1)
```

## Arguments

- concentration:

  Positive concentration parameter.

## Value

An object of class `btsbm_partition_prior`.

## Examples

``` r
dirichlet_process_prior()
#> <clustering_prior> Dirichlet process(concentration = 1) 
```
